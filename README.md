# AquaPocket ’99 — Tactile Hardware Study 01

Interactive 3D translucent water-ring handheld console, real-time hydrodynamic jet turbulence & ring-peg physics, 4 frosted polycarbonate shell colorways (Glacier, Atomic Purple, Smoke, Coral), and procedural WebAudio foley in a single self-contained HTML file (Three.js + custom GLSL, zero external textures, models, or audio samples).

- **Controls:** Press the 3D silicone buttons (or hold **A** / **D** or **Left** / **Right** arrows) to pump water jets & bubbles · Drag the handheld shell to tilt & slosh · Drag the background to orbit (**Shake** / **Reset** for another round).
